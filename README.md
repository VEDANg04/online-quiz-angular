# Online Quiz Application (Angular)

This is a simple Online Quiz Application developed using Angular.  
The project allows users to attempt a multiple-choice quiz with a timer and view the result at the end.

## Features

- Multiple choice questions (MCQs)
- Timer for each question (30 seconds)
- Automatic navigation to next question when time ends
- Result page showing score and pass/fail status
- Admin panel to add and delete quiz questions
- Questions stored using browser LocalStorage
- Clean and simple user interface

## Technologies Used

- Angular
- TypeScript
- HTML
- CSS
- Angular Material

## Project Structure

- Quiz Component – Displays questions and handles quiz logic
- Admin Component – Allows adding and deleting questions
- Result Component – Displays quiz result
- Quiz Service – Manages questions and score

## How to Run the Project

1. Clone the repository
2. Run `npm install`
3. Run `ng serve`
4. Open `http://localhost:4200` in the browser

## Admin Panel

- Navigate to `/admin` to access the admin panel
- Admin can add new questions and delete existing ones
